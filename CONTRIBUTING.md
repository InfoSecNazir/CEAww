# Contributing / المساهمة

## English

1. Read [the project guide](README.md) and [file index](docs/INDEX.md).
2. Create a focused branch from `main`. For public repositories, fork first if you do not have write access.
3. Follow the dependency manager and build commands documented for this repository; do not copy setup commands from another project.
4. Run existing relevant checks when changing code. For documentation changes, verify referenced paths and commands.
5. Keep Arabic and English documentation aligned. Describe the change and the checks actually performed in your pull request.

Use fictional fixtures. Keep credentials, local environment files, personal records, and generated environments out of new commits. Preserve existing license notices and upstream attribution.

## العربية

1. اقرأ [دليل المشروع](README_AR.md) و[فهرس الملفات](docs/INDEX_AR.md).
2. أنشئ فرعاً لتغيير محدد انطلاقاً من `main`. في المستودعات العامة، أنشئ Fork أولاً إذا لم تكن لديك صلاحية كتابة.
3. اتبع مدير الحزم وأوامر البناء الخاصة بهذا المستودع، ولا تنسخ أوامر إعداد من مشروع مختلف.
4. شغّل الفحوص المناسبة الموجودة عند تعديل الكود. لتعديل التوثيق، تحقق من المسارات والأوامر المشار إليها.
5. حافظ على توافق التوثيق العربي والإنجليزي، واذكر التغيير والفحوص التي أجريتها فعلياً في طلب الدمج.

استخدم بيانات تجريبية وهمية. أبقِ بيانات الدخول وملفات البيئة المحلية والسجلات الشخصية والبيئات المولدة خارج الالتزامات الجديدة. حافظ على إشعارات الترخيص ونسبة العمل إلى مؤلفيه.
